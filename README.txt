Felipe Callejas Music Portfolio — GitHub Pages package

1. Create a new public GitHub repository.
2. Upload ALL contents of this folder, preserving the assets folders.
3. Make sure index.html is in the repository root.
4. In GitHub: Settings > Pages > Build and deployment > Deploy from a branch.
5. Select main and /(root), then Save.
6. GitHub will show the public URL for the portfolio.

Important: Do not upload only index.html; it needs the assets folder beside it.
